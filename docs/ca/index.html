# Quant a

pgAdmin III és la plataforma de codi obert més popular per a l'administració i el desenvolupament de PostgreSQL. El projecte original es va retirar a favor del pgAdmin 4 basat en web, però aquest fork comunitari manté viva l'aplicació nativa wxWidgets: corregeix errors per a versions modernes de PostgreSQL i afegeix desenes de funcions noves.

Aquesta versió presenta un port natiu complet per a macOS per a Apple Silicon (arm64), distribuït com un paquet .app autònom mitjançant Homebrew Cask.

  • Repositori: github.com/heptau/pgadmin3
  • Fork ascendent: levinsv/pgadmin3 (Suport per a PostgreSQL 18)
  • Projecte original: postgres/pgadmin3 (archived)

# Característiques principals

🖥️ macOS natiu

Una autèntica aplicació nativa construïda sobre wxWidgets 3.3 + Cocoa. Sense Electron, sense Java — petjada de memòria baixa, inici ràpid.

🐘 PostgreSQL 12–18

Suport complet per a versions modernes de PostgreSQL, PostgresPro Enterprise, replicació Slony-I i programació de pgAgent.

🔍 Editor SQL

Ressaltat de sintaxi, detecció automàtica de la sentència sota el cursor, pestanyes amb desament automàtic, múltiples finestres de resultats, transformacions de text amb PCRE.

📊 Eina de consultes

Adreces d'interès amb nom, autocompleció de joins mitjançant claus foranes, nombres grans llegibles, vista de diff per comparació de cel·les.

🔄 Eines d'esquema

Comparació d'objectes entre servidors amb informes diff HTML, control de versions amb GitLab, comprovació d'índexs B-tree mitjançant amcheck.

📈 Monitorització

Finestra d'estat / activitat del servidor, ressaltat de processos, mostreig d'esdeveniments d'espera (pg_wait_sampling), informes AWR, visor de registres CSV.

🎨 Barra d'eines SVG

Icones modernes SVG per a la barra d'eines, preparades per a HiDPI / Retina, codificació de color per servidor.

🌐 Localització

45 idiomes inclosos, tots amb fonts .po editables. Els buits de txec, espanyol, alemany, francès, rus, polonès, xinès i letó omplerts a la v2026.07.14.

🔌 Connectors

Extensible mitjançant mòduls connector — afegeix funcionalitat personalitzada sense modificar el nucli.

🔐 SSL / SSH

Xifrat de connexió SSL/TLS i tunelització SSH (libssh2) per a accés segur al servidor.

# Instal·lació

macOS (Apple Silicon) — via més ràpida

Binari precompil·lat mitjançant Homebrew Cask:

brew install heptau/tap/pgadmin3

Inicia des de Launchpad, Spotlight o la terminal:

open /Applications/pgAdmin\ III.app

Compil·la des del codi font (macOS)

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
open "build-macos/pgAdmin III.app"

Nota: La primera compilació requereix una wxWidgets 3.3 compilada localment (amb --disable-std_containers). El bottle de Homebrew no és compatible — consulteu AGENTS.md per a més detalls.

Linux

git clone https://github.com/heptau/pgadmin3.git
cd pgadmin3
make build
./build/pgAdmin3

Windows

Obriu pgAdmin3.vcxproj al Visual Studio, o compileu creuat des de Linux amb mingw — consulteu INSTALL_EN.txt.
